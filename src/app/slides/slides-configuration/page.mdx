# Slides configuration




The **`.slides`** [layerdocs-stdlib/com.layerdocs.stdlib.module.Slides/slides.html](https://layerdocs.com/docs/layerdocs-stdlib/com.layerdocs.stdlib.module.Slides/slides.html) function allows you to override the default configuration of `slides` documents. All of its parameters are **optional**:

| Parameter      | Description                                                                                       | Accepts                         | Default                         |
|----------------|---------------------------------------------------------------------------------------------------|---------------------------------|---------------------------------|
| `center`       | Whether content should be centered vertically.                                                    | [`Boolean`](boolean)         | Up to the current layout theme. |
| `controls`     | Whether navigation controls should be shown.                                                      | [`Boolean`](boolean)         | `true`                          |
| `speakernotes` | Whether [speaker notes](slides-speaker-notes) should be displayed outside of the speaker view. | [`Boolean`](boolean)         | `false`                         |
| `transition`   | Transition style between slides.                                                                  | `none`, `fade`, `slide`, `zoom` | `slide`                         |
| `speed`        | Transition speed between slides.<br/>Requires `transition` to be set.                             | `default`, `fast`, `slow`       | `default`                       |
