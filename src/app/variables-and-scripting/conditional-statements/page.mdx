# Conditional statements




The **`.if`** function creates a conditional statement:

1. The first parameter is the [`boolean`](boolean) condition to evaluate.
2. The second parameter is a parameter-less [lambda](lambda) that runs only if the condition is true.

```layerdocs
.examplemirror
    .if \{yes\}
        Hello, LayerDocs!

```
## Nesting

The function returns the lambda's result if the condition is satisfied, or nothing otherwise. This means the function *propagates* its content up the call stack.

```layerdocs
.examplemirror
    <!-- Read this from bottom to top -->

    .if \{yes\}
        .if \{no\}
            .if \{yes\}
                .if \{yes\}
                    Hello!

```
This behavior lets you use the function as part of any expression. For example, you can use it to conditionally include content inside layout functions, such as [stacks](stacks).

```layerdocs
.examplemirror
    .row gap:\{1cm\}
        A

        .if \{.iseven \{3\}\}
            B

        C

```
## Negation

The **`.ifnot`** function is a shorthand that inverts `.if`'s behavior, returning a value only if the condition is *not* satisfied.

LayerDocs does not yet have an *else* statement, but you can emulate one using the [`.let`](let) function:

```layerdocs
.examplemirror
    .let \{.iseven \{3\}\}
        condition:
        .if \{.condition\}
            3 is even!
        .ifnot \{.condition\}
            3 is odd!

```
> Tip: `.ifnot \{.condition\}` is equivalent to `.if \{.condition::not\}`
