# Image size




While base Markdown requires HTML code to constrain the size of an image, LayerDocs introduces a syntax extension that achieves the same result more elegantly: `!(WIDTHxHEIGHT)[ALT](/logo.png)`.

```layerdocs
.exampleoutput \{!(300x100)[Icon](/logo.png)\} prelude:\{The following equivalent examples load `image.png` with the label `Alt` as CommonMark Markdown does, but also add a size constraint that fits the visible image into a 300px by 100px box.\}
    \!(300x100)[Alt](/logo.png)

    <!-- or -->

    \!(300*100)[Alt](/logo.png)

    <!-- or -->

    \!(300 100)[Alt](/logo.png)

```
In addition to pixels (whose unit can be omitted), any other [size](sizes) unit is supported. When using other units, you must use either `*` or a space as the delimiter instead of `x`.

```markdown
!(5cm*35mm)[Alt](/logo.png)

<!-- or -->

!(2.5in 1cm)[Alt](/logo.png)

<!-- but not this -->

!(2.5inx1cm)[Alt](/logo.png)

<!-- '%' is an exception. This is valid (although not very readable) -->

!(30%x150%)[Alt](/logo.png)
```

## Automatic dimension

When you set either component (width or height) to `_` (underscore), it becomes automatic, meaning that component is calculated to preserve the original aspect ratio.

### Auto height

```markdown
<!-- 300px width, auto height -->
!(300x_)[Alt](/logo.png)

<!-- 5cm width, auto height -->
!(5cm*_)[Alt](/logo.png)

<!-- 2in width, auto height -->
!(2in _)[Alt](/logo.png)

<!-- 50% width, auto height -->
!(50% _)[Alt](/logo.png)
```

As a convenient shorthand, you can omit the automatic height entirely:

```markdown
<!-- 300px width, auto height -->
!(300)[Alt](/logo.png)

<!-- 5cm width, auto height -->
!(5cm)[Alt](/logo.png)

<!-- 2in width, auto height -->
!(2in)[Alt](/logo.png)

<!-- 50% width, auto height -->
!(50%)[Alt](/logo.png)
```

### Auto width

```html
<!-- auto width, 100px height -->
!(_x100)[Alt](/logo.png)

<!-- auto width, 15mm height -->
!(_*15mm)[Alt](/logo.png)

<!-- auto width, 2in height -->
!(_ 2in)[Alt](/logo.png)
```
