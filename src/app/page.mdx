  **LayerDocs** (formerly Quarkdown) is designed for technical writers who need more control than standard Markdown but want to maintain the speed of a text-based workflow.
</Callout>

### Core Concepts

*   **Modular Architecture**: Include and reference files dynamically.
*   **Built-in Functions**: Powerful primitives for layout, tables, and charts.
*   **Variables & Scripting**: Use logic inside your documentation.
*   **Multi-Output**: Generate high-quality PDFs and interactive websites from the same source.
