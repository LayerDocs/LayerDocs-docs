# Introduction

Welcome to **LayerDocs**, the modern typesetting system designed for performance and simplicity.

## What is LayerDocs?

LayerDocs is a powerful document engine that allows you to create professional PDFs using a simple, Markdown-based syntax. Unlike traditional typesetting systems that are heavy and complex, LayerDocs is built to be:

*   **⚡ Lightweight**: Under 10MB total installation size.
*   **🚀 Fast**: Renders 10+ page documents in milliseconds.
*   **💎 Professional**: High-fidelity output designed for modern technical reports.
*   **💻 Universal**: Runs perfectly on Google Colab, CI/CD, and low-RAM devices.

## Why choose LayerDocs?

In the modern world, document generation is often bloated. Most tools require a full browser engine (Chromium) or a heavy runtime (Java) to produce high-quality PDFs. This leads to crashes in constrained environments like Google Colab.

LayerDocs solves this by using a **Pure Python** engine (powered by ReportLab) for its Lite version, and a modular Kotlin core for its Pro features.

## Core Features

*   **Markdown Support**: Use standard Markdown for headers, lists, and formatting.
*   **LaTeX Math**: Render complex formulas with a clean, mathematical font.
*   **Structured Components**: Use `.box` components for tips, warnings, and errors.
*   **Pro Syntax Highlighting**: Highlight code blocks in any language.
