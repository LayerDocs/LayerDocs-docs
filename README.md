# LayerDocs Documentation

Welcome to the official documentation for **LayerDocs**, a versatile Markdown-based typesetting system designed for modularity and depth.

## 🚀 Getting Started

LayerDocs can be installed via PyPI as a Python package, providing a lightweight wrapper for professional PDF and HTML generation.

### Installation

```bash
pip install layerdocs
```

### Quick Usage

```python
import layerdocs

# Compile a Quarkdown file to PDF
layerdocs.compile("main.qd", output_type="pdf")
```

## 🛠️ Features

- **Modular Syntax**: Use `.function {arg}` for powerful document control.
- **AI Studio**: Interactive editor with real-time preview and Ollama integration.
- **Premium Themes**: Built-in support for high-quality PDF and HTML outputs.
- **Lightweight & Fast**: Built with Kotlin and modern web technologies.

## 💻 Local Development

This documentation site is built with [Next.js](https://nextjs.org) and [Nextra](https://nextra.site).

### Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
